Tratamiento de datos de la demostración

Versión personal-data-v1 · vigente desde el 15 de agosto de 2026.

Use exclusivamente datos sintéticos. La aplicación solicita nombre, correo, teléfono y dirección sólo para demostrar el checkout y la entrega.

Datos de tarjeta

El backend no recibe ni almacena número de tarjeta, código de seguridad ni vencimiento. El método fake produce únicamente un identificador opaco y efímero.

Uso y retención

Los datos se limitan al checkout local, no se incluyen en logs ni evidencia y deben eliminarse cuando termine la evaluación. Los tokens de aceptación y pago no se persisten.

Consulta

La referencia local del intento permite revisar el estado sin publicar información personal ni datos de pago.
